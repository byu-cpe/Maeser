# The example Directory

This directory contains several useful resources for setting up your own Maeser application. `example/` is organized into the following directories:

- **`apps/`:** Contains example implementations of Maeser. These scripts are a great starting point for building your own application.
- **`resources/`:** Contains static resources used by the Flask web application and contains the vector stores used by the chatbot.
- **`tools/`:** Contains the Python scripts used to generate the BYU and Karl G. Maeser vector stores as well as a generic `embeddings_example.py` script that you can alter to create your own vector store.

For more information on these resources, see [**Maeser Example (with Flask & User Management)**](https://byu-cpe.github.io/Maeser/development/flask_example.html) and [**Embedding New Content**](https://byu-cpe.github.io/Maeser/development/embedding.html) in the documentation.
